# 已知问题与限制 / Known Issues & Limitations — v0.6.0 RC

**尚未验证 / Not yet verified**
- Windows 与 macOS 包已构建但**未在实机运行**（BUILT — RUNTIME NOT VERIFIED）。Windows and macOS builds have not been run on those systems.
- 未经真人试玩、扬声器/耳机试听、实体手柄（含震动）测试；难度与手感来自自动化测试与模拟玩家。No human playtest, listening test or physical-controller test yet; tuning comes from automated tests and simulated players.
- 英文文本未经母语者校对。English text has not been proofread by a native speaker.
- 真实显卡帧率仅在旧版本（v0.4.0，Apple M6）实测；本版性能数据来自软件渲染。Real-GPU frame times were measured only on v0.4.0.

**已知限制 / Known limitations**
- Windows 未做代码签名（SmartScreen 会提示）；macOS 未公证（需右键 → 打开）。Not code-signed / notarized.
- 书法标题保持中文（英文模式下也是）。Calligraphy titles stay in Chinese by design.
- 手柄菜单使用 Xbox 布局（A 确认 / B 返回）；任天堂布局手柄上 A/B 位置相反。Menus use the Xbox layout (A confirm / B back).
- 精简画质以 1280×720 渲染后放大，大屏上略软。*Low graphics* renders at 1280×720 and upscales (slightly softer).
- 本试玩版只含第一章序章（五个区域 + 尸将）。This demo contains the Chapter 1 prologue only.
